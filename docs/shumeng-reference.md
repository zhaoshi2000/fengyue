# 数梦参考项目与本地实现

用户提供的 `D:\workspace\shumeng-backend` 是 Java 后端；`D:\workspace\shumeng-backend-web` 是管理和作者后台。面向读者的网页在同一工作区的 `D:\workspace\shumeng-frontend-web`。这些目录只作为功能与交互参考，风月项目代码和数据库仍独立运行。

| 模块 | 数梦参考 | 风月当前实现 | 后续差异 |
| --- | --- | --- | --- |
| 账号与内容 | 注册、作者、作品、用户内容 | 注册登录、角色卡发布、收藏关注与历史 | 作者资料与更完整的作品审核流程 |
| 角色卡与世界 | 作品设定、MOD、世界内容 | 人设、场景、开场白、示例、世界书触发词、作者 CSS | MOD 安装、版本和依赖管理 |
| 聊天 | 流式输出、停止、消息管理、模型和会话配置、导出 | 模型回复持久化、消息编辑删除、重新生成、会话重命名与 TXT 导出 | 流式输出与停止、独立会话配置、长会话分页 |
| 管理 | 作品、用户、推荐、评论、模型、订单、结算等 | 用户和作品管理、基本统计 | 审核、推荐、评论、模型配置；支付与结算需独立业务设计 |

世界书条目按顺序保存。触发词以中英文逗号或顿号分隔，命中用户本轮消息或最近六条对话时启用；触发词为空的条目每轮启用。禁用条目不会送入模型。单次注入最多 6000 字，以控制上下文长度。
